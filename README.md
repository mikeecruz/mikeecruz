## Abordagem de engenharia

```text
Requisitos claros → arquitetura adequada → implementação sustentável → entrega confiável
```

Meu trabalho é guiado por alguns princípios:

- **Visão de produto e negócio** para entender o problema antes de definir a solução
- **Arquitetura pragmática** com decisões proporcionais ao contexto e à escala
- **Código legível e sustentável** para facilitar manutenção e evolução
- **Integrações confiáveis** com atenção a contratos, dados e tratamento de falhas
- **Automação de processos** para reduzir tarefas repetitivas e tornar fluxos mais consistentes
- **Evolução incremental** para modernizar sistemas com segurança e continuidade
